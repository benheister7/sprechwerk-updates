# Sprechwerk – Downloads

Diktieren auf Deutsch für den Mac: Taste halten, sprechen, loslassen – der Text landet dort, wo der Cursor steht.
Spracherkennung und KI laufen komplett auf dem Gerät, ohne Konto und ohne Cloud.

**Installieren:** [Sprechwerk-Mac.zip herunterladen](https://github.com/benheister7/sprechwerk-updates/releases/latest/download/Sprechwerk-Mac.zip), entpacken, `Sprechwerk.app` in „Programme“ ziehen. Die Anleitung liegt in der Zip.

Updates kommen danach automatisch – Sprechwerk fragt, sobald eine neue Version da ist.

Voraussetzungen: Mac mit Apple-Chip, macOS 26 oder neuer.
