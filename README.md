# Flüster – Downloads

Lokales Diktieren auf Deutsch für den Mac. Spracherkennung und KI laufen komplett auf dem Gerät.

**Installieren:** [Fluester-Mac.zip herunterladen](https://github.com/benheister7/fluester-updates/releases/latest/download/Fluester-Mac.zip), entpacken, `Flüster.app` in „Programme“ ziehen. Die Anleitung liegt in der Zip.

Updates kommen danach automatisch – Flüster fragt, sobald eine neue Version da ist.

Voraussetzungen: Mac mit Apple-Chip, macOS 26 oder neuer.
